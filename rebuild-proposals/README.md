# Rebuild Proposals

Dieser Ordner enthaelt neue Visual- oder SVG-Vorschlaege fuer den Basis-Seminar-Rebuild.

Der Viewer vergleicht alte Folien-PNGs mit SVG-Vorschlaegen aus:

```text
rebuild-proposals/svg/
```

Empfohlene Struktur:

```text
rebuild-proposals/
  svg/
    RE1/
      slide_001.svg
      slide_002.svg
```

Die alten Folien-PNGs liegen parallel unter:

```text
source-materials/basis-seminar/png/RE1/slide_001.png
```
