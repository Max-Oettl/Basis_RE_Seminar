# Modulvorlage

Die fuenf stabilen Modul-IDs sind `RE1` bis `RE5`. Lege Quell-SVGs und Word-Sprechertexte in getrennte Pflichtunterordner:

```text
<module_id>/SVG/slide_001.svg
<module_id>/SVG/slide_002.svg
<module_id>/Text/slide_001.docx
<module_id>/Text/slide_002.docx
```

Optionale lokale Referenzen der SVG-Exporte duerfen unter `<module_id>/SVG/assets/` liegen. Die Originaldateien werden nicht veraendert.
