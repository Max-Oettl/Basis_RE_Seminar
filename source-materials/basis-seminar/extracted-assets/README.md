# Extracted Assets

Hier liegen wiederverwendbare Bilder aus dem Basis-Seminar.

Beispiele:

```text
source-materials/basis-seminar/extracted-assets/RE1/slide_012_image_01.png
source-materials/basis-seminar/extracted-assets/RE3/slide_045_diagram_context.png
```

## Zweck

Dieser Ordner ist fuer komplexe Darstellungen gedacht, die besser als bestehendes Bild uebernommen werden, statt sie neu zu erfinden.

Moegliche Quellen:

- Originalbild vom Nutzer nachgereicht
- Crop aus Folien-PNG
- Screenshot aus PDF oder PowerPoint

## Regeln

- Dateinamen enthalten Modul, Foliennummer und kurze Bildrolle.
- Bilder mit eingebranntem Fachtext werden nur uebernommen, wenn der Text nicht sinnvoll als editierbarer Text rekonstruiert werden kann.
- Im Rebuild-JSON wird dokumentiert, ob das Bild final uebernommen, nur als Referenz genutzt oder neu aufgebaut werden soll.
