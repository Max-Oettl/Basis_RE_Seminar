# Image Library

Dieses Verzeichnis enthaelt wiederverwendbare Rasterillustrationen und
Rasterpiktogramme fuer RelTest-Education-Lerninhalte.

Jedes Bildasset besitzt ein gleichnamiges `.asset.json` mit Herkunft, Nutzungszweck, technischen Pflichtmerkmalen und den Folien, auf denen es verwendet werden darf. Bei der Produktion wird das Asset in den jeweiligen Folienordner kopiert; die zentrale Datei bleibt die kanonische Quelle.

Der Dateibestand allein ist keine aktuelle Stilfreigabe. Aeltere generierte
Piktogramme muessen vor erneuter Verwendung gegen
`workflow/30-visual-decision/pictogram-creation-workflow.md` und das Stilprofil
`reltest-education-minimal-v1` geprueft werden. 3D-, isometrische, verlaufende,
schattierte, texturierte oder nicht transparent freigestellte Assets gelten als
Legacy und duerfen nicht als neue Education-Piktogramme wiederverwendet werden.
