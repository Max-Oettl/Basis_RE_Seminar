# Extracted Source Text

Dieser Ordner enthaelt abgeleitete, wortgetreue Markdown-Extraktionen der Word-Sprechertexte.

Kanonische Struktur:

```text
analysis/source-text/<module_id>/extracted/<docx-stem>.md
```

Die DOCX-Originale bleiben unter `source-materials/basis-seminar/powerpoint-svg/<module_id>/Text/`. Eine Extraktion ist nur zusammen mit ihrem Eintrag in `analysis/inventories/<module_id>_svg-text-map.json` gueltig. Dort stehen Quellpfad, Hash, Mapping-Methode und die zugeordnete Quell-SVG.

Diese Dateien duerfen nicht als frei bearbeitete Sprechertexte verwendet werden. Inhaltliche Aenderungen muessen aus einer neuen freigegebenen Word-Quelle stammen und fuehren zu neuen Hashes sowie einem erneuten Mapping-QA.
