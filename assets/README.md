# Assets

Dieses Verzeichnis enthaelt Legacy- und Downstream-Produktionsdaten aus dem alten Storyboard-/SVG-Workflow.

Fuer die neue Basis-Seminar-Rebuild-Analyse werden hier standardmaessig keine Dateien erzeugt. Der neue Primaeroutput liegt unter:

```text
analysis/
```

## Wann Dieser Ordner Wieder Relevant Ist

`assets/scenes/` wird erst wieder genutzt, wenn der Nutzer nach abgeschlossener Analyse ausdruecklich eine SVG-, PNG-Asset- oder E-Learning-Video-Produktion beauftragt.

Dann gelten die bestehenden Legacy-Workflowdateien:

- `workflow/scene-by-scene-production-runbook.md`
- `workflow/graphic-creation-quality-gate.md`
- `workflow/diagram-guidelines.md`
- `agents/production-orchestrator.md`

## Bestehende Inhalte

Vorhandene Szenenordner, Manifeste, Prompts, Previews und komponierte SVGs bleiben erhalten und werden durch die Rebuild-Analyse nicht automatisch veraendert.
